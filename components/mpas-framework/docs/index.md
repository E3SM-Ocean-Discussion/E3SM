# MPAS Framework

The MPAS framework is the infrastructure shared by the MPAS components in E3SM: MPAS-Ocean,
MPAS-Seaice and MALI. It provides the mesh and data types, domain decomposition and halo
exchanges, I/O and streams, timekeeping, common operators, and the registry tools that generate
each component's variables, namelists and streams. Its source is in `components/mpas-framework/src`.

These pages cover the framework itself and work that spans more than one MPAS component.
